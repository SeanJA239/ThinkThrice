# ThinkThrice 团队进度同步

更新于 2026-11-21。给全体队友看，包括不写代码的同学。技术细节见 [HANDOFF.md](HANDOFF.md)。

## 一句话

ThinkThrice（三思）是一个聊天 App：你发出的消息如果被手机上的模型判断为「冲动」，就不会立刻送出，而是先「冻住」冷静一会儿。之后你可以等它冷静好再发、改写、走完几道思考题后硬发，或者干脆放下。这是赛道 2「逆向 UX」：用户会讨厌它，但它确实让人少发后悔的消息。

## 现在已经能用的功能

都在模拟器里完整跑通过，自动化测试也通过了。

**聊天和冷静**
- 三个预设聊天对象：前任、老板、组员。对方会按剧本自动回复。
- 发出的消息先由手机上的模型打分（不联网）。冲动的消息会变成冻在冰壳里的气泡，带雪花动画和震动，下面显示倒计时：白天冷静 15 分钟，深夜（22:00–6:00）冷静到第二天早上 9:00。
- 点冻住的消息，有四个选择：
  - **现在就要发**：要先过思考题，每题跟着呼吸花慢慢呼吸 3 次（约 15 秒）才能继续。白天 1 题，深夜 3 题。
  - **等它冷静下来**：到时间后会收到通知「昨晚 1:47 的那条冷静好了」，点一下确认就发出。
  - **改写**：原文一句一句「解冻」进编辑框，改完重新打分。冷静了就送达，还冲动就继续冻着。
  - **放下**：消息碎成冰屑消失。
- 「双方冷静 15 分钟」：右上角的雪花，双方都暂停一会儿。
- 列表里会显示还有几条消息冻着；深夜聊天背景会变成星空，冻住消息时会下雪。

**这一轮新加的**
- **灵动岛**：有消息冻着时，灵动岛上显示雪花和倒计时，长按展开显示「给老板的 1 条消息 · 正在冷静」；冷静好了会变成「好了」并弹一下。锁屏上也有。为保护隐私，不显示消息原文。
- **Face ID**：在设置里打开「查看冷静中的消息需要 Face ID」后，冻住的消息会被模糊，点开要先刷 Face ID。
- 用词统一为「冷静」（以前有些地方叫「沉淀」）。
- 个人主页入口变大，加了玻璃质感；成就徽章可以点（还没有详情页）；状态里的「显示离线」改叫「离线」；分享时会带 ThinkThrice 的图标。
- 深色模式下联系人卡片的按钮颜色改浅，更好认；修了列表分隔线缺一截的问题。

**其他页面**
- 「三思」页：本周总结（像 iPhone 屏幕使用时间那样的一段话）、三思指数、14 天图表。首次打开会有两周示例数据，设置里可以清除。
- 个人主页、联系人卡片（状态、备注、免打扰、置顶）、联系人搜索。
- **演示面板**：在聊天里长按顶部联系人，可以把时间跳到深夜 01:30、快进到早上 9:00 或快进 15 分钟，调锁定线，测试任意一句话的冲动分数，或清空重来。

## 还没做 / 还没验证

- **还没在真 iPhone 上跑过**。震动、通知横幅、灵动岛、Face ID、模型速度都只在模拟器里看过，这是最优先要验证的。
- **模型第一次要联网准备**：新手机第一次打开 App 时，系统要下载中文语言资源，大约 1 分钟，之前只能靠关键词规则判断。上台前，演示机要先联网打开 App 几分钟，并在演示面板里确认「中文 BERT 资源：已就绪」。
- **两台手机互发**：功能已写好，但从没在两台真机上试过。是否放进演示待定。
- 设置里的「通知开关」「提示音」只是保存了，还没生效。
- 灵动岛上没有「放下」按钮（是刻意的：放下要回到 App 里想清楚再做）；成就徽章没有详情页；电话、视频、搜索聊天记录只做了界面。
- 思考题和剧本回复是草稿文案，在 `App/Resources/Questions.json` 和 `Scripts.json` 里，可以直接改。
- 模型已知的弱点，上台时避开：拐弯抹角的复合（「你还会想起我吗」）、对前任的平常事（「你的伞还在我这…」）、反讽（「行，你开心就好」）、普通抱怨（「堵车堵了一小时气死我了」）。

## 接下来的工作（按人）

**App：Sean**
1. 在自己的 iPhone 上跑通，按下面「舞台脚本」走一遍：重点看灵动岛、Face ID、通知、震动。
2. 把 App 装到队友手机上（步骤见下文）。
3. 用真机重录备用演示视频（现有的是模拟器录的，没有震动，还录进了演示面板）。
4. 决定两台手机互发要不要上台；要上的话，先用两台真机试。
5. 和讲稿同学对齐：演示要走哪几步、每步讲哪个设计点。

**模型 / 规则：睿洋**
1. 在真 iPhone 上确认演示面板的模型一栏显示 `ThinkThriceAnger`（不是 Lite 备用模型），并测一下打分速度。
2. 用演示面板的「测试一句话」把舞台台词逐句再测一遍，深夜和白天各一次。
3. 想补的关键词或台词，可以直接发给 Sean，或者自己改 `ThinkThriceRules.swift` 并补测试。
4. 准备评委可能问的模型问题：数据从哪来、准确率多少、为什么在手机上跑、误判怎么办。

**非技术同学**
1. **用户研究**：找几个人（同学、朋友）聊一聊「你发过最后悔的消息是什么、在什么时候发的」。记下原话和数量（例如「8 个人里 6 个是深夜发的」），讲稿和海报会用到。
2. **海报（必须用 Dify 的 AMD 插件生成）**：注册 AMD 开发者账号拿 API Key → 在 Dify 装「AMD Free Token Factory」插件 → 建工作流让模型输出 HTML 海报 → 导出后精修，换上真实截图。**保留工作流截图和生成记录作为证据**。详细步骤见[赛道调研文档](https://ampcode.com/artifacts/swift-2-1-ebcace9e-1833-453b-97b9-2d273e7ed82d)第 4 节。插件只生成文字和排版，不生成图片，截图要自己放进去。
3. **讲稿 / 答辩**：3 分钟。主办方要讲清「背后的设计思路」，并且至少有三处「刻意让人抓狂」的设计。建议用这张表：每处抓狂 → 为什么让人抓狂 → 它保护了什么。候选：消息被冻住不能发、硬发要先呼吸着过思考题、改写时原文一句一句才出来、深夜一律冻到早上、查看冻住的消息要刷 Face ID。再准备一份评委问答（见下文「还缺」）。
4. **演示彩排**：照舞台脚本至少完整走 3 遍，计时。准备一个出问题时的预案：卡住就切到备用录屏。
5. **备用录屏**：Sean 用真机重录后，下载到演示电脑本地，不要依赖现场网络。

## 把 App 装到你的 iPhone 上（用 Sean 的 Mac）

**先确认三件事**
- 你的 iPhone 是 **iOS 26 或更新**（设置 → 通用 → 关于本机）。iPhone 14 Pro 以后的大多数机型有灵动岛（16e、17e 这类 e 系列没有）；没有灵动岛的手机，倒计时只出现在锁屏上。
- 有一根能传数据的数据线，iPhone 设了锁屏密码（Face ID 功能要用到）。
- **Sean 先确认自己用的是免费账号还是付费开发者账号**：Xcode → Settings → Accounts，团队名后面写着「(Personal Team)」的就是免费账号。

**免费 Apple 账号（Personal Team）的限制**（来源：[Apple 官方说明](https://developer.apple.com/help/account/basics/about-your-developer-account)）
- **最多登记 3 台设备**，登记 7 天后失效。这 3 台**包括 Sean 自己的手机**，所以算上 Sean，最多 3 人能装。
- 每台手机最多装 3 个这样的 App。
- 装上的 App **7 天后打不开**，要再连一次 Mac 重新运行一次。黑客松 48 小时内不受影响，但别太早装。
- 付费开发者账号（每年 99 美元）没有这几条限制，一年可登记 100 台设备，装上的 App 有效期约一年。

**步骤（第一次装大约 10 分钟）**
1. 用数据线把 iPhone 连到 Sean 的 Mac，解锁 iPhone，弹出「要信任此电脑吗」时点「信任」并输入密码。
2. **打开开发者模式**：iPhone 设置 → 隐私与安全性 → 拉到最下面「开发者模式」→ 打开 → 按提示重启。重启后再点「打开」并输入密码。（这个选项要先连过 Mac 才会出现；看不到的话，先让 Sean 在 Xcode 里选一次你的手机。）
3. Sean 在 Xcode 顶部的设备菜单里选你的 iPhone，点 ▶︎ 运行。第一次会比较慢；Xcode 可能会提示把你的手机登记到账号上，同意即可。
4. 如果 iPhone 提示「不受信任的开发者」：设置 → 通用 → VPN 与设备管理 → 点开发者账号 → 信任。然后再打开 App。
5. 第一次打开时：允许通知；**联网放一两分钟**，让模型准备好中文资源。
6. 以后不用再插线：同一 Wi-Fi 下，Sean 可以在 Xcode 的设备管理窗口（Devices / Device Hub）里给这台手机打开网络连接，之后无线就能装新版本。

**更新到最新版**：Sean 在 Mac 上拉取最新代码后重新点运行即可，手机里的数据会保留。想清空重来：演示面板 →「清空所有对话」。

## 舞台脚本（已验证）

开场前：演示面板 →「清空所有对话」，确认「中文 BERT 资源：已就绪」。

1. **老板**：发「老板我今天需要请一个病假」→ 直接送达。
2. **老板**：发「你是不是脑子有问题？天天让人加班」→ 冻住。点开看「为什么被冻住」，回到桌面看灵动岛倒计时。
3. **前任**：发「在吗」→ 直接送达。
4. 演示面板 →「跳到 01:30（深夜）」，背景变星空。**前任**：发「我想复合了」→ 冻住（只在深夜才会冻）。
5. 点这条消息 →「当晚就要发」→ 跟着呼吸花走一题后点「算了」。
6. 演示面板 →「快进到 09:00」→ 通知「昨晚 1:30 的那条冷静好了」，灵动岛变成「好了」→ 选择发送或者放下。
